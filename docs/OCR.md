# Overview

100OCRAPI provides OCR APIs for:
- Passports
- National IDs
- Driver licenses
- Handwriting recognition

The Passport OCR API extracts MRZ and passport fields from uploaded passport images and returns structured JSON.

The API is designed for:
- KYC systems
- Onboarding automation
- Travel check-in systems
- Identity verification
- Fintech applications

Supported:
- 200+ countries
- ICAO-compliant passports
- REST API integration
- Base64 image upload

Claims from docs:
- ~99%+ extraction accuracy
- Sub-second processing
- Structured JSON responses
